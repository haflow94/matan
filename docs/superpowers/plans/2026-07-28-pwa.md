# PWA Matan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre l'app Matan installable sur Android et fonctionnelle hors-ligne via PWA.

**Architecture:** `@ducanh2912/next-pwa` génère automatiquement le service worker via `next.config.ts`. Le manifest est déclaré dans `app/manifest.ts` (App Router natif). Les icônes sont des PNG générés depuis SVG (lettre م sur fond teal).

**Tech Stack:** Next.js 16 App Router, `@ducanh2912/next-pwa`, SVG→PNG via sharp ou canvas Node.js

### Task 2 : Générer les icônes PNG

**Files:**
- Create: `scripts/generate-icons.mjs`
- Create: `public/icon-192.png`
- Create: `public/icon-512.png`
- Create: `public/apple-touch-icon.png`

- [ ] **Étape 1 : Créer le script de génération**

Créer `scripts/generate-icons.mjs` :

```js
import sharp from 'sharp';

// SVG source : lettre م blanche, fond teal #186A4C, filet gold #B8863B en bas
function makeSvg(size) {
  const barH = Math.round(size * 0.06);
  const fontSize = Math.round(size * 0.52);
  return `<svg xmlns="http://www.w3.org/2000/svg" width="${size}" height="${size}" viewBox="0 0 ${size} ${size}">
  <rect width="${size}" height="${size}" fill="#186A4C" rx="${Math.round(size * 0.18)}"/>
  <rect x="0" y="${size - barH}" width="${size}" height="${barH}" fill="#B8863B" rx="0"/>
  <text
    x="50%" y="54%"
    dominant-baseline="middle"
    text-anchor="middle"
    font-family="serif"
    font-size="${fontSize}"
    fill="white"
  >م</text>
</svg>`;
}

const sizes = [
  { name: 'icon-192.png', size: 192 },
  { name: 'icon-512.png', size: 512 },
  { name: 'apple-touch-icon.png', size: 180 },
];

for (const { name, size } of sizes) {
  await sharp(Buffer.from(makeSvg(size)))
    .png()
    .toFile(`public/${name}`);
  console.log(`✓ public/${name}`);
}
```
